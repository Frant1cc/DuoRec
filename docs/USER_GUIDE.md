# 使用指南

[← 返回 DuoRec](../README.md)

## 下载安装

1. 从 [GitHub Releases](https://github.com/Frant1cc/DuoRec/releases/latest) 下载 macOS 通用版 DMG，需要 macOS 26 或更高版本。
2. 打开 DMG，将 `DuoRec.app` 拖入“应用程序”。也可下载 ZIP，解压后将 App 移至“应用程序”。
3. 从“应用程序”启动 DuoRec，再授予录音所需权限。

当前安装包使用临时签名，未经过 Apple Developer ID 签名和公证。如果首次打开被系统拦截，仅在确认来源可信时，先尝试打开 App，再在“系统设置 > 隐私与安全性”中选择“仍要打开”，详见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。

通用包包含 Apple 芯片与 Intel 二进制文件。本机转写使用 Whisper；Apple 芯片优先使用 Metal 加速，Intel 使用 CPU。首次使用需要下载或导入模型。

## 窗口布局

主窗口采用可折叠侧边栏，提供“录音”“转写”和“语言识别”三个入口，窗口可自由调整大小。录音期间底部持续显示状态、时长和“停止并保存”，切换到转写页也可以停止录音。侧边栏底部的“设置”可查看权限和检查更新，也可按 ⌘, 打开。

## 开始录音

1. 启动 DuoRec，在侧边栏选择“录音”；如提示缺少权限，点击“授予权限”，按系统提示允许屏幕与系统音频录制、麦克风访问。
2. 如果系统提示需要重新打开 App，请完全退出后从原位置重新打开。
3. 选择麦克风和保存位置。默认保存到当前用户的 `下载/DuoRec`。
4. 播放一段声音并对麦克风说话，点击“测试输入”确认两条电平条都会变化。测试期间不会保存声音。
5. 点击“开始录音”，结束后点击“停止并保存”。

建议佩戴耳机，避免扬声器声音再次进入麦克风而产生重音。

每次录音正常保存只生成一个 MP4 文件：

```text
2026-10-31 14-30-00 DuoRec.mp4
```

MP4 内只有音频，不包含屏幕画面。默认混音轨用于直接回听，另有系统声音与麦克风两条独立来源音轨供转写使用。来源标记保存在文件内部，移动或重命名不需要配套文件；转写时会跳过混音轨，避免重复识别。只有一路声音时，文件保留混音与该路来源音轨。

## 语言识别与模型下载

打开侧边栏的 **“语言识别”**，选择以下四个多语言模型之一：

| 模型 | 磁盘大小约 | 用途 |
| --- | ---: | --- |
| large-v3 | 3.10 GB | 准确率优先，资源占用最高 |
| large-v3-turbo | 1.62 GB | 大模型加速版，默认选项 |
| small | 488 MB | 内存占用较低 |
| medium | 1.53 GB | 兼顾识别效果与资源占用 |

每行显示磁盘大小和“下载”按钮。连接服务器时显示连接状态，收到数据后显示已下载大小、总大小和百分比。点击“暂停”会保留未完成文件，按钮变为“继续下载”；关闭窗口、退出应用或网络中断后，重新打开仍可从已保存的字节继续。连续 30 秒未收到数据会提示超时并保留已下载部分。只有点击暂停模型右侧的删除按钮才会主动丢弃未完成的下载。

续传使用 HTTP Range，并检查服务器返回的起始位置与文件总大小；若服务器忽略续传请求，会安全地重新下载完整文件，避免拼接出错误模型。下载完整后校验真实文件大小与 SHA-256，通过后才显示“已下载”。校验失败会保留文件并给出具体原因；完整文件可点击“重新校验”，不会再次联网下载，主动删除后才会从头下载。模型运行时还需要额外内存和临时音频空间。

模型文件从 Hugging Face 下载；无法连接时，可先自行下载对应的 **原版、未量化 ggml .bin 文件**，选中该模型后点击“导入模型…”。导入同样会检查文件完整性。模型保存在 DuoRec 的应用支持目录，不随关闭窗口删除。模型选择会在下次启动恢复。

录音语言始终自动识别，按原语言转写，不翻译，也不局限于中文和英语。中文和粤语转写统一使用简体，英文及日文等其他语言保留原文。应用在语音停顿处分段，每段最长 30 秒，分别检测语言，避免整条音轨被开头的语言锁定。旧版本保存的固定语言选项会自动清除。短句、噪声、同一句内频繁切换语言仍可能影响准确率。转写期间不能选择或删除模型；切换到其他页面不会取消任务。

## 录音转文字

在侧边栏选择“转写”，点击右上角工具栏中的“导入音频”，选择音频文件：

- 导入新录制的 MP4 即可按来源转写；此前保存的带来源标记的单文件 MOV 也可使用。
- 导入旧版 DuoRec 的 M4A 时，应用仍会查找同文件夹内的同名 `.tracks.mov`，也可直接导入 `.tracks.mov`。旧版配对文件需要保留同名关系。
- 双轨转写按时间顺序显示每段话，并标明“系统声音”或“麦克风”。顶部可筛选全部内容或单一来源。
- 工具栏只保留一个“复制”按钮，复制当前选中的文字，未选中文字时置灰。也可按 ⌘C 复制，按 ⌘A 全选后复制当前显示的全部文字。复制成功时底部显示“已复制到剪贴板”。
- 普通单轨音频可转写和修改文字；已混合且没有来源音轨的录音无法准确区分系统声音与麦克风。

转写使用“语言识别”页选中的 Whisper 模型，自动识别录音语言；界面语言不影响转写语言。转写不会修改导入的录音，不生成文字文件，也不保留历史；切换页面不会取消转写或清除文字，来源筛选也会保留；需要保存的文字请在关闭主窗口前复制。

## 隐私与权限

DuoRec 不上传录音，不包含分析统计或第三方在线转写服务。下载模型会连接 Hugging Face；模型准备完成后可离线转写，转写过程在本机进行，不调用 Apple Speech 或第三方在线转写接口。

支持应用内更新的版本可从“设置”窗口、DuoRec 菜单或菜单栏面板点击「检查更新…」，下载后安装并重启。检查更新会连接 GitHub 获取版本信息和更新包，不上传录音，不在后台自动安装。录音、测试输入、保存期间不能检查更新；更新对话框打开后暂停开始新录音，取消或检查结束后恢复。

旧版本需要手动安装一次首个支持在线更新的版本。更新不主动清除偏好设置和保存位置，但录音权限由 macOS 管理，从临时签名迁移到固定自签名身份时可能需要重新授权，后续也不能保证完全没有系统权限提示。

系统声音采集使用 ScreenCaptureKit，因此需要“屏幕与系统音频录制”权限；应用只接收音频，不保存屏幕画面。可在“系统设置 > 隐私与安全性”中管理或撤销权限。

录音文件会保留在保存文件夹中；转写时临时提取的单路音频会在转写结束或取消后清理。中断文件可能保留在应用的数据目录中等待恢复。关闭主窗口会取消当前转写并清空其中的文字，但不会删除录音文件或已经复制到剪贴板的内容。

## 录音保存与中断恢复

- 采集发生异常时自动停止计时，并尝试保存已经收到的声音。
- 录音中按 ⌘Q 退出，会等待保存完成。无法保存可播放的文件时会取消退出，并保留原始文件。
- 意外崩溃或强制结束后，下次启动会尝试将中断文件恢复到所选保存位置。无法恢复时可使用“打开待恢复文件夹”查看原文件。
- 正常保存会生成一个 MP4，原始来源 AAC 音轨直接封装到文件内，只有默认混音轨会重新编码。完整保存前会保留可恢复的采集文件；MP4 保存失败时，应用会尝试保留可播放的原始 MOV，并提示保存结果。

录制中的 MOV 会分段写入，首次约 1 秒，随后每 5 秒写入一个片段。强制结束可能丢失最后未写入的片段；首个片段完成前的短录音、磁盘故障，以及旧版未收尾的 M4A 不保证可恢复。重要录音建议先做短录测试，停止后确认文件可播放。

## 常见问题

**权限已开启，但仍无法录音**

确认授予权限的是当前运行的 DuoRec 副本，完全退出后从相同位置重新打开。可在 App 中打开权限设置并重新检查。自行构建或更换签名后，macOS 可能要求重新授权。

**模型无法下载或无法转写**

先在“语言识别”页确认当前模型显示“已下载”。无法连接 Hugging Face 时，可导入对应模型的原版、未量化 ggml .bin 文件；校验失败请重新下载完整文件。加载失败时可释放内存或切换 small；磁盘还需要保留临时音频转换空间。模型不可用时仍可录音。

**系统声音或麦克风没有电平**

确认正在播放声音、麦克风选择正确，并检查两项权限。系统声音不包含 DuoRec 自身播放的声音。

**切换界面语言**

在“系统设置 > 通用 > 语言与地区 > 应用程序”中为 DuoRec 选择简体中文或英语，然后重新打开 App。

## 录音设置

- 系统声音：48 kHz / 128 kbps AAC。
- 麦克风：48 kHz / 64 kbps AAC，可选择关闭增强、+6 dB 或 +12 dB 增强。
- 默认混音：48 kHz / 128 kbps AAC。混音轨和来源音轨都在同一个 MP4 内。
- 保存文件夹可自行选择，应用会在下次启动时保留选择。

## 旧版录音

较早版本会保存混音 `.m4a` 和同名 `.tracks.mov`。这些文件不会自动转换或删除；需要按来源转写时，请继续保留两份文件的配对关系。新录音使用单文件 MP4，无需配套文件。
